Keyboard Shortcuts Cheat Sheet

A practical shortcut cheat sheet for Mac and Windows with editing, windows, browser, screenshots and app-switching shortcuts.

Mac shortcutsWindows shortcutsBrowser tabsScreenshots

Mac editing and files

Copy: ⌘ + C
Paste: ⌘ + V
Cut: ⌘ + X
Undo: ⌘ + Z
Redo: ⌘ + Shift + Z
Select all: ⌘ + A
Duplicate line: ⌘ + D
Save: ⌘ + S
Open: ⌘ + O
New tab: ⌘ + T
Close tab: ⌘ + W
Print: ⌘ + P

Windows editing and files

Copy: Ctrl + C
Paste: Ctrl + V
Cut: Ctrl + X
Undo: Ctrl + Z
Redo: Ctrl + Shift + Z
Select all: Ctrl + A
Duplicate line: Ctrl + D
Save: Ctrl + S
Open: Ctrl + O
New tab: Ctrl + T
Close tab: Ctrl + W
Print: Ctrl + P

Mac search and browser

Find: ⌘ + F
Replace: ⌘ + H
Find next: Enter
Find previous: Shift + Enter
Command palette: ⌘ + Shift + P
Refresh: ⌘ + R
Reopen tab: ⌘ + Shift + T
Bookmark: ⌘ + D
Address bar: ⌘ + L
New window: ⌘ + N
History: ⌘ + H

Windows search and browser

Find: Ctrl + F
Replace: Ctrl + H
Find next: F3
Find previous: Shift + F3
Command palette: Ctrl + Shift + P
Refresh: Ctrl + R
Reopen tab: Ctrl + Shift + T
Bookmark: Ctrl + D
Address bar: Ctrl + L
New window: Ctrl + N
History: Ctrl + H

Mac navigation

Next tab: ⌘ + Tab
Previous tab: ⌘ + Shift + Tab
Move by word: Option + Arrow
Top or bottom: ⌘ + Up / Down

Windows navigation

Next tab: Ctrl + Tab
Previous tab: Ctrl + Shift + Tab
Move by word: Ctrl + Arrow
Top or bottom: Ctrl + Home / End

Screenshots

Mac selected area: Shift + Cmd + 4
Mac full screen: Shift + Cmd + 3
Windows snip: Win + Shift + S
Windows full screen: Win + PrtScn

Mac system and apps

Switch app: ⌘ + Tab
Force quit: ⌘ + Option + Esc
Lock screen: Ctrl + Cmd + Q
Emoji picker: Ctrl + Cmd + Space

Windows system and apps

Switch app: Alt + Tab
Task manager: Ctrl + Shift + Esc
Lock screen: Win + L
Emoji picker: Win + .
