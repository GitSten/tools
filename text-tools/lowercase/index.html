What lower case does

Lower case uncapitalizes every letter. "Reset The Password" becomes "reset the password". It is the fastest way to undo a caps-lock paste when you do not need sentence capitals yet.

People search for this when a form, username, or file name must be lowercase. CSS classes, URL paths, package names, and many database keys are written entirely in lower case. A single capital letter can make a username or a class name fail a check that compares text exactly.

Hyphens and underscores are kept. If you wanted those separators normalized, use kebab-case or snake_case after this step. For a normal sentence, sentence case is the better second click, because lower case removes the capital at the start of the sentence too.

What this will not fix

  • Spelling. The letters change case only.
  • Language-specific pairs such as Turkish İ. The tool uses Unicode's default mapping, not a locale.
  • Meaning. A lowercased brand name may violate that brand's writing rules. Check the name before you publish it.

Questions

Is the text uploaded?

No. Conversion happens in this browser. The text is not sent to a ToolsNowPro server.

Does the result cost anything?

No. You can copy or download it without an account.

Will proper names stay capitalized?

Only if the format you chose keeps them. Sentence case lowercases the sentence first, so check names afterward.
