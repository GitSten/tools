What snake_case does

snake_case separates words with underscores and writes every letter in lower case. "User Login Count" becomes "user_login_count". Hyphens and spaces become underscores. camelCase and PascalCase are split before the underscores are added, so "userLoginCount" becomes "user_login_count".

Python variables, many database columns, and a lot of file names use this pattern. Ruby and PHP use it widely too.

Environment variables are the same shape in upper case: LAST_LOGIN_AT. Make snake_case first, then open UPPER CASE and convert the result. Doing it in that order keeps the underscores.

If the destination is a URL or a CSS class, you usually want hyphens instead. That format is kebab-case. If the destination is a JavaScript variable, use camelCase.

Is the text uploaded?

No. Conversion happens in this browser. The text is not sent to a ToolsNowPro server.

Does the result cost anything?

No. You can copy or download it without an account.

Will proper names stay capitalized?

Only if the format you chose keeps them. Sentence case lowercases the sentence first, so check names afterward.
