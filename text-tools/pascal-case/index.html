What PascalCase does

PascalCase capitalizes every word and removes the separators. "login form" becomes "LoginForm". It is camelCase with a capital first letter. Use it for classes, React components, and type names. Use camelCase for variables and functions.

Before and after

InputPascalCase

already_snake_caseAlreadySnakeCase

The converter splits on spaces, hyphens, underscores, and on a lowercase letter followed by a capital. "alreadySnakeCase" becomes "AlreadySnakeCase". A block of capitals without spaces is one word: "HTTPResponse" stays a single token and becomes "Httpresponse" after the first letter is capitalized and the rest is lowercased inside that word. Spell the words apart if you need "HttpResponse".

PascalCase is a code format, not a headline format. Readers of a blog post should see title case or sentence case, which keep the spaces.

Is the text uploaded?

No. You can copy or download it without an account.

Will proper names stay capitalized?

Only if the format you chose keeps them. Sentence case lowercases the sentence first, so check names afterward.
