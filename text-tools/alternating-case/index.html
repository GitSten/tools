What alternating case does

Alternating case walks through the letters and flips between upper and lower case. "hello there" becomes "HeLlO tHeRe". Spaces, numbers, and punctuation do not take a turn, so the pattern does not drift when the sentence has commas.

This is a style effect for a meme, a username experiment, or a single emphasized word. It is a poor choice for an email, a document, or anything you want people to read quickly. If the text was a caps-lock accident, use sentence case instead.

Inverse case is different. Inverse case swaps whatever case each letter already has, so "Hello" becomes "hELLO". Alternating case ignores the original case and starts again from a capital on the first letter.

Running alternating case twice does not restore the original. The second pass starts from the already alternating letters and flips them again. Keep a copy of the source text if you might want it back. The box converts what is currently in it.

Questions

Is the text uploaded?

No. Conversion happens in this browser. The text is not sent to a ToolsNowPro server.

Does the result cost anything?

No. You can copy or download it without an account.

Will proper names stay capitalized?

Only if the format you chose keeps them. Sentence case lowercases the sentence first, so check names afterward.

When should I use Alternating case?

Alternate capital and lowercase letters for a stylistic look. Punctuation and spaces stay put, so the pattern follows the letters only.
